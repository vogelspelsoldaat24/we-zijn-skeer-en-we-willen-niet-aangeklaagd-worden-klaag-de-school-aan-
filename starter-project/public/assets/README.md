# Monsterbeelden en bronvermelding

De twee meegeleverde SVG-monsters zijn originele, eenvoudige placeholderillustraties. Je mag ze voor dit project vervangen.

Wil je Pokémon-sprites gebruiken, raadpleeg bijvoorbeeld de sprite-repository van PokeAPI:
https://github.com/PokeAPI/sprites

Let op: Pokémon is auteursrechtelijk beschermd. De beschikbaarheid van de sprites betekent niet automatisch dat je ze vrij mag hergebruiken. Controleer schoolbeleid en gebruiksvoorwaarden; voor een openbare release zijn eigen of passend gelicentieerde monsterillustraties veiliger.

Vermeld bij iedere toegevoegde asset: naam, bronlink, maker/rechthebbende en (indien van toepassing) licentie.
